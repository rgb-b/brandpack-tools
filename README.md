# WorkBase — Self-Hosted Workplace Management

A configurable, self-hosted internal toolset. PIN-based auth, SQLite database, runs on your local network or behind a reverse proxy.

---

## Stack

Express + SQLite + Vanilla JS/Vite · Node.js ≥ 18 · systemd (prod)

---

## Fresh Install

### 1. Install dependencies

```bash
npm run install:all
```

### 2. Create your env file

```bash
cp server/.env.example server/.env
# Edit SESSION_SECRET with a long random string
```

### 3. Start development server

```bash
npm run dev
# Server: http://localhost:8080
# Client: http://localhost:5173
```

### 4. Run setup wizard

Open http://localhost:5173 — the setup wizard will appear on first boot.

Steps: **Name your app → Choose tools → Add equipment → Create admin account**

This creates `config.json` at the project root (gitignored) and your first admin user in the database.

## Production (systemd)

### Build the client

```bash
cd client && npm run build
```

### Install and start service

```bash
# Copy service file
sudo cp work-tools.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable work-tools
sudo systemctl start work-tools
```

### Switch from the redesign build

```bash
# Stop and disable the redesign service
sudo systemctl stop work-tools-redesign.service
sudo systemctl disable work-tools-redesign.service

# Rebuild and restart original
cd /home/el/Documents/El-Projects/work-tools/client
npm run build
sudo systemctl restart work-tools.service
```

## Config

### config.json (generated by setup wizard)

```json
{
  "app": {
    "name": "Your App Name",
    "tagline": "Optional tagline",
    "primaryColor": "#ff6b35",
    "logoText": "Y"
  },
  "setup_complete": true,
  "tools": {
    "inventory":       { "enabled": true,  "label": "Inventory" },
    "productivity-v4": { "enabled": true,  "label": "Tasks" },
    "maintenance":     { "enabled": true,  "label": "Maintenance" },
    "pantone":         { "enabled": false, "label": "Colour Library" },
    "converter":       { "enabled": false, "label": "Converter" },
    "admin":           { "enabled": true,  "label": "Admin" }
  },
  "equipment": []
}
```

Edit this file or use **Admin → App Settings** to change branding and toggle tools.

### server/.env

```
PORT=8080
HOST=0.0.0.0
SESSION_SECRET=your-long-random-secret
NODE_ENV=production
```

## Commands

| Command | Description |
|---|---|
| `npm run install:all` | Install root + server + client deps |
| `npm run dev` | Dev mode: server (8080) + client (5173) |
| `npm run dev:server` | Server only |
| `npm run dev:client` | Client only |
| `npm run build` | Production Vite build → client/dist/ |
| `npm run migrate` | Init/reset DB schema |

---

## Tools

| Key | Default | Description |
|---|---|---|
| `inventory` | on | Supply and stock tracking |
| `productivity-v4` | on | Task tracking and time sessions |
| `maintenance` | on | Equipment issues and service log |
| `pantone` | off | Colour matching and status tracker |
| `converter` | off | LAB ↔ CMYK colour conversion |
| `admin` | on | User and PIN management |

Enable/disable any tool via `config.json` or Admin → App Settings. Disabled tools are hidden from the launcher.

---

## Data

- **Database:** `server/data/brandpack.db` (SQLite)
- **Backup:** copy the `.db` file anywhere
- **Equipment** is managed in Admin → Equipment and stored in the database
- **Users** and sessions are PIN-based (4–8 digits)
